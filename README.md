Connect 4 Game with borrowed initial code from https://github.com/KeithGalli/Connect4-Python/blob/master/connect4_with_ai.py 

The main goal for this project is to add a menu function to allow for greater customization and various gameplay modes.

Sub-goals for this code include the following:

__Player Modes__

- Single (player vs AI)
- Offline Multiplayer

__Game Style Modes__

- Connect 5 Mode: Expand the board size to allow for a Connect 5 win condition.
- Double Move Mode: Each player is allowed to make two moves per turn.
- Speed mode (each player gets 3 seconds to make a move)

__Game Setting Customization__
- Menu background music toggle (on/off)
- Game background music toggle (on/off)
- Chip Drop Sound effect toggle (on/off)
- Win sound effect toggle (on/off)
- Lose sound effect toggle (on/off)
